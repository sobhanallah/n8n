# Product Card With Cart Icon

این کد یک کارت محصول ساخته شده با کامپوننت Card از دیزاین سیستم دیگ است که هدر، توضیح، و یک اکشن با آیکون سبد خرید (shopping-cart) از مجموعه آیکون‌های Digcheh را در گوشه بالا ارائه می‌دهد.

- از `Card` و زیرکامپوننت‌هایش مثل `CardHeader`, `CardTitle`, `CardDescription`, `CardContent`, و مهم‌تر از همه `CardAction` برای تعبیه اکشن نمادین (سبد خرید) استفاده‌شده است.
- آیکون `shopping-cart` دقیقاً مختص سناریو خرید است و به صورت SVG یکپارچه شده.
- نمونه برای کارت توضیح محصول، دکمه خرید یا افزودن به سبد خرید مناسب است.

برای تغییر متن یا گسترش محتوا می‌توانید مقادیر props یا کودهای محتوایی را عوض کنید.
